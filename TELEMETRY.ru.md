# Телеметрия MCPC

В независимой сборке MCPC телеметрия по умолчанию выключена. Клиент возвращает `false` из `telemetryEnabled()`, пока при сборке явно не задано:

```text
VITE_MCPC_TELEMETRY_ENABLED=true
```

Параметр проверяется во время сборки. Пользовательская настройка может отключить телеметрию в сборке, где она включена, но не может включить её, если сборка оставила функцию выключенной.

## Если телеметрия включена в сборке MCPC

Клиент из [src/lib/telemetry.ts](src/lib/telemetry.ts) собирает события и отправляет их в настроенный API MCPC:

- `POST /launcher/telemetry` — пакеты событий.
- `POST /launcher/heartbeat` — состояние лобби и игры.

Базовый адрес задаётся через `VITE_MCPC_API_BASE_URL`. Rust-ядро использует `MCPC_API_BASE_URL`.

Унаследованная реализация может собирать сведения об устройстве и системе, запусках и выходах из игры, установках и импорте, ошибках и сбоях, просмотренных экранах и действиях интерфейса, поисковых запросах в виде метаданных, действиях покупки и производительности. Перед включением изучите [src/lib/telemetry.ts](src/lib/telemetry.ts), [src/lib/telemetryPrivacy.ts](src/lib/telemetryPrivacy.ts) и [src/lib/crashEvent.ts](src/lib/crashEvent.ts).

## Обязанности оператора

Перед включением телеметрии в распространяемых сборках MCPC должен опубликовать собственную политику конфиденциальности. В ней нужно описать точные поля, которые хранит сервер MCPC, сроки хранения, контроль доступа, удаление данных и возможность связи событий с учётной записью.

По умолчанию в проекте не настроены ни адрес телеметрии, ни учётная запись прежнего издателя. Не направляйте клиент к API другого издателя.
